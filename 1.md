
# 转换类型

- 值无损：源类型的值可以无损地转换为目标类型的值，转换到目标类型的值再转换回源类型的值，结果与原始值相同。
- 表示无损：转换过程中，底层表示不会改变，即必须长度相同且位级相等。
- 成功保证：转换操作在所有情况下都能成功完成。
- 稳定性：第一次来回转换后的结果与第二次来回转换后的结果相同。
- 来回转换：源类型能转换为目标类型则目标类型一定能转换回源类型，不一定要求支持相同类型的转换。

| 名称                                                    | 值无损             | 表示无损           | 稳定性             | 成功保证 | 来回转换          |
|---------------------------------------------------------|--------------------|--------------------|--------------------|----------|-------------------|
| 值保持转换 / Value-Preserving Conversion                | 是                 | 否                 | 是                 | 是       | 必须              |
| 可失败值保持转换 / Fallible Value-Preserving Conversion | 是                 | 否                 | 第一次转换成功时是 | 否       | 成功时必须        |
| 规范化转换 / Canonicalizing Conversion                  | 否                 | 否                 | 是                 | 是       | 必须              |
| 可失败规范化转换 / Fallible Canonicalizing Conversion   | 否                 | 否                 | 是                 | 否       | 成功时必须        |
| 重解释 / Reinterpretation                               | 否                 | 是                 | 是 (编译器保证)    | 是       | 必须 (编译器保证) |
| 视图变换 / View Transformation                          | 持有引用，该项无效 | 持有引用，该项无效 | 是                 | 是       | 只能转换回视图    |
| 可失败视图变换 / Fallible View Transformation           | 持有引用，该项无效 | 持有引用，该项无效 | 是                 | 否       | 只能转换回视图    |
| 无保证转换 / Unrestricted Conversion                    | 否                 | 否                 | 否                 | 是       | 可选              |
| 可失败无保证转换 / Fallible Unrestricted Conversion     | 否                 | 否                 | 否                 | 否       | 可选              |
